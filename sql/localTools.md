ou can connect to a PostgreSQL database inside GitHub Codespaces using a desktop client (like DBeaver, pgAdmin, or TablePlus). Because Codespaces runs in an isolated environment, you must use SSH forwarding or the GitHub CLI to securely expose the database port to your local machine.Here is the step-by-step guide to connect securely:1. Open Codespaces in VS Code DesktopYou cannot easily connect to a database over raw public URLs, so you need to open your active Codespace inside your local VS Code application:In your browser, click the Code button in your repository, go to the Codespaces tab, and select Open in Visual Studio Code (or open VS Code on your desktop, sign in, and open the Codespace from the Codespaces extension).2. Forward the PostgreSQL PortOnce your Codespace is active and the database is running:Open the Terminal in VS Code.Select the PORTS tab at the bottom of the window.If port 5432 isn't listed, click Add Port and enter 5432.Right-click the port and ensure its Port Visibility is set to Private to keep it secure.3. Connect from Your Desktop ClientNow that the port is forwarded locally, it is securely bound to 127.0.0.1. Open your preferred SQL desktop client and use these connection details:Host: 127.0.0.1 (or localhost)Port: 5432 (or whichever local forwarded port you assigned)Database Name: The name of your database (e.g., postgres or your custom app name)Username: The Codespace database user (e.g., postgres)Password: Your database passwordAlternative: Use the GitHub CLI (gh)If you prefer not to use VS Code Desktop to forward the port, you can do it via the command line using the GitHub CLI:Make sure you are authenticated in your terminal by running gh auth login.Run the following command to forward the Codespace port to your local machine:gh codespace ports forward 5432:5432 -c <your-codespace-name>Leave this terminal window open, then configure your desktop database client using 127.0.0.1 and 5432.Prefer an In-Browser GUI?If you want to view tables or run queries directly in your Codespace without downloading a desktop client, you can use built-in extensions. You can install the SQLTools extension, or add pgAdmin to your Codespace container
