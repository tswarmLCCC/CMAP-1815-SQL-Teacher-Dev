# Project Guidelines & Rules

## Video Integration
All custom course videos produced by the instructor are indexed in `shared_assets/VideoMap.md` and governed by the rules in [.agents/rules/video_mapping.md](file:///.agents/rules/video_mapping.md).
- Format: `<Video Label / Pattern> - <URL>`
- Course Orientation: Embedded in `wiki_content/start-here.html` and linked in `course_settings/syllabus.html`.
- Unit Lectures: Embedded in `unit-XX-readings-and-media.html` under Section 4.
- Unit Labs: Embedded in `unit-XX-student-lab-guide.html`.
- Cartridge build scripts dynamically parse `shared_assets/VideoMap.md` when compiling `CMAP_1815_Complete.imscc`.

## Emoticon & Emoji Policy
Governed by [.agents/rules/emoticon_usage.md](file:///.agents/rules/emoticon_usage.md).
- Emoticons and emojis are eliminated across assistant responses, Canvas pages, course guides, and code scripts.
- May only be used VERY sparingly for great effect.
